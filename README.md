- **Prompt สำคัญ:**
  1. *"ฉันมีลิงก์งานออกแบบจาก Figma (แนบลิงก์) โปรดช่วยวิเคราะห์โครงสร้างเว็บไซต์นี้ แล้วเขียนโค้ด HTML5 โดยใช้ Bootstrap 5 Grid System (container, row, col) ในการแบ่งสัดส่วนหน้าเว็บให้ตรงกับดีไซน์ แบ่งเป็น Section ย่อยๆ ให้ชัดเจน (เช่น Navbar, Hero Banner, Content, Footer) ยังไม่ต้องใส่ CSS แบบละเอียด ขอแค่โครงสร้างที่ถูกต้องก่อน"*
  2. *"จากโครงสร้าง HTML ที่ได้ ให้ช่วยเขียนไฟล์ style.css แยกต่างหาก โดยดึงค่าสี (Color Palette) และฟอนต์ (Typography) ให้ตรงกับใน Figma มากที่สุด และที่สำคัญคือต้องทำให้เว็บเป็น Responsive รองรับการแสดงผลบนมือถือ (Mobile-friendly) หากมีส่วนไหนที่บนหน้าจอคอมเป็นแนวนอน ให้ปรับเป็นแนวตั้ง (Stack) เมื่อดูผ่านมือถือ"*
  3. *"ในหน้า 'สัตว์น้ำจิ๋ว' (animals.html) ฉันไม่อยากให้ปุ่ม 'อ่านรายละเอียด' เด้งไปหน้าใหม่ ช่วยแก้ไขโค้ดปุ่มและการ์ด ให้ทำงานร่วมกับ Bootstrap Modal (หน้าต่าง Pop-up) แทน เมื่อกดปุ่มแล้วให้มีหน้าต่างเด้งขึ้นมาพร้อมแสดงข้อมูลของสัตว์ตัวนั้นๆ โดยที่หน้าเว็บยังคงสไตล์เดิมจาก Figma ไว้"*
- **ผลลัพธ์ที่นำมาใช้โดยตรง:** เนื้อหาความรู้และรายละเอียดของสัตว์น้ำ/บทความ ที่ AI ช่วยเขียนเพิ่มเติมให้สมบูรณ์ นำมาใส่ใน Modal
- **ผลลัพธ์ที่ต้องแก้ไข และแก้ไขอย่างไร:** เดิมที AI ช่วยแปลงไฟล์เป็นนามสกุล `.php` แต่เพื่อให้โปรเจกต์นี้สามารถนำขึ้น GitHub Pages (Static Hosting) ได้ จึงต้องสั่งให้ AI เขียนสคริปต์เพื่อเปลี่ยนโค้ดและลิงก์ทั้งหมดกลับมาเป็น `.html` ล้วน
- **ตรวจสอบความถูกต้องอย่างไร:** นำโค้ดทั้งหมดมารันและทดสอบการกดปุ่ม "อ่านรายละเอียด" ทุกปุ่มในเครื่องตัวเอง (Local) และใช้ฟีเจอร์ Responsive Mode ใน Chrome DevTools เพื่อจำลองการย่อหน้าจอเพื่อทดสอบระบบมือถือ
- **ตัวอย่างคำตอบที่ AI ให้ผิดและแก้ปัญหาอย่างไร:** ตัวอย่างเช่น ตอนสั่งให้ AI แปลงโค้ด AI ทำการบันทึกไฟล์ผิดฟอร์แมต ทำให้ภาษาไทยกลายเป็นตัวยึกยือ (Mojibake/Encoding Error) ผู้จัดทำแก้ปัญหาโดยสั่งให้ AI เขียนสคริปต์แก้ Encoding ให้กลับมาเป็น UTF-8 เพื่อให้แสดงภาษาไทยได้ถูกต้อง
- **สิ่งที่ได้เรียนรู้จากการใช้ AI:** การใช้ AI ช่วยลดเวลาการพิมพ์ข้อมูลได้มาก และช่วยตรวจจับจุดบกพร่อง (ลิงก์ตาย) ที่เรามองข้ามไปได้ แต่เราในฐานะผู้พัฒนาต้องเข้าใจโครงสร้างเว็บพื้นฐานก่อน เพื่อที่จะสามารถตรวจสอบความถูกต้องและสั่งให้ AI ทำงานแก้ไขปัญหาได้อย่างตรงจุด

- **ขั้นตอน Deploy:**

## 🛠️ คู่มือการแก้ไข UI (UI Customization Guide)
หากอาจารย์หรือผู้ประเมินต้องการทดสอบแก้ไขงานสด (Live Coding Test) สามารถอ้างอิงวิธีการแก้ไขจุดต่างๆ ได้ดังนี้:

### 1. การแก้ไขปุ่ม (Buttons)
เว็บไซต์นี้ใช้คลาสปุ่มของ **Bootstrap 5** ผสมกับ Custom CSS 

**1.1 การเปลี่ยนสีปุ่ม (Button Colors)**
ไปที่ไฟล์ HTML (เช่น `index.html` หรือ `animals.html`) ค้นหาปุ่มที่ต้องการเปลี่ยน ตัวอย่างคลาสสีของ Bootstrap:
*   `btn-primary` (สีน้ำเงิน) เปลี่ยนเป็น `btn-danger` (สีแดง)
*   `btn-outline-primary` (ปุ่มขอบสีน้ำเงิน) เปลี่ยนเป็น `btn-outline-success` (ปุ่มขอบสีเขียว)
*   `btn-dark` (สีดำ) เปลี่ยนเป็น `btn-warning` (สีเหลือง)

**ตัวอย่างโค้ดเดิม:**
```html
<a href="animals.html" class="btn btn-outline-primary rounded-pill...">ดูทั้งหมด</a>
```
**วิธีแก้:**
```html
<!-- เปลี่ยนเป็นปุ่มทึบสีแดง -->
<a href="animals.html" class="btn btn-danger rounded-pill...">ดูทั้งหมด</a>
```

**1.2 การเปลี่ยนขนาดปุ่ม (Button Sizes)**
สามารถเพิ่มคลาสกำหนดขนาดต่อท้ายคลาส `btn` ได้เลย:
*   `btn-sm` (ปุ่มขนาดเล็ก)
*   `btn-lg` (ปุ่มขนาดใหญ่)
*   หากลบออกจะเป็นขนาดมาตรฐาน (Default)

**ตัวอย่างโค้ดเดิม (ปุ่มเล็ก):**
```html
<a href="#" class="btn btn-outline-secondary btn-sm">รายละเอียด &gt;</a>
```
**วิธีแก้ (เปลี่ยนเป็นปุ่มใหญ่):**
```html
<a href="#" class="btn btn-outline-secondary btn-lg">รายละเอียด &gt;</a>
```

### 2. การแก้ไขสีหลักของเว็บไซต์ (Theme Colors)
หากต้องการเปลี่ยนโทนสีของเว็บทั้งเว็บ (เช่น เปลี่ยนจากโทนสีฟ้าเป็นสีเขียว) ให้ไปที่ไฟล์ **`style.css` บรรทัดที่ 2-10** (ส่วน `:root`)

**ตัวอย่างโค้ดเดิม:**
```css
:root {
    --primary-blue: #0077b6; /* สีหลัก */
    --light-blue: #e0fbfc;   /* สีพื้นหลังอ่อน */
    --dark-blue: #1e21db;    /* สีเข้ม (ตัวอักษร) */
    --accent-blue: #00b4d8;  /* สีเน้นลูกเล่น */
}
```
**วิธีแก้:** แค่เปลี่ยนรหัสสี HEX (เช่น `#0077b6`) เป็นรหัสสีอื่น ตัวเว็บที่ดึงตัวแปรนี้ไปใช้จะเปลี่ยนสีตามทันที

### 3. การแก้ไขข้อความและฟอนต์
*   **ขนาดตัวอักษร:** ใน HTML มีการใช้คลาส `fs-1` ถึง `fs-6` (Font Size ของ Bootstrap) ในการคุมขนาดตัวอักษร `fs-1` คือใหญ่สุด `fs-6` คือเล็กสุด สามารถเปลี่ยนตัวเลขตรงนี้ได้เลย
*   **ความหนาตัวอักษร:** ใช้คลาส `fw-bold` (หนามาก), `fw-medium` (หนากลาง), `fw-light` (บาง) 

**ตัวอย่างการแก้ขนาดความหนา:**
```html
<!-- เดิม: ตัวหนาและใหญ่ระดับ 1 -->
<h2 class="fw-bold fs-1">สัตว์น้ำจิ๋ว</h2>

<!-- แก้เป็น: ตัวบางและเล็กลงระดับ 3 -->
<h2 class="fw-light fs-3">สัตว์น้ำจิ๋ว</h2>
```
