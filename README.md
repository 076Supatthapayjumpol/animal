## 🎯 วัตถุประสงค์ (Project Objectives)
- เพื่อสร้างเว็บไซต์ที่รวบรวมและนำเสนอข้อมูลเกี่ยวกับสัตว์น้ำขนาดเล็กให้น่าสนใจและเข้าถึงง่าย
- **กลุ่มเป้าหมาย:** นักเรียน นักศึกษา และบุคคลทั่วไปที่สนใจศึกษาเรื่องสัตว์น้ำ ระบบนิเวศ และชีววิทยา

## 💻 เทคโนโลยีที่ใช้ (Technology Stack)
- **Design:** Figma
- **Frontend:** HTML5, CSS3, JavaScript
- **CSS / UI:** Bootstrap 5, เขียน CSS เพิ่มเติม (Custom CSS), AOS Animation สำหรับลูกเล่นเลื่อนหน้า, Bootstrap Icons
- **Framework:** ไม่ใช้ Framework (Pure HTML/JS)
- **Build Tool:** ไม่ใช้
- **Assets:** Google Fonts (Kanit), Bootstrap Icons
- **Version Control:** Git และ GitHub
- **Hosting:** GitHub Pages
- **AI Tools:** Google Gemini (Antigravity IDE)
- **Testing:** Chrome DevTools, Responsive Mode (ตรวจสอบขนาดหน้าจอมือถือและไอแพด)

## ✨ ฟังก์ชันหลัก (Features)
- **ระบบคลังข้อมูลสัตว์น้ำ:** แสดงรายการและข้อมูลสัตว์น้ำจิ๋วแบบละเอียดผ่านหน้าต่าง Pop-up (Modal) โดยไม่ต้องโหลดหน้าใหม่
- **ระบบบทความและเกร็ดความรู้:** หน้าอ่านบทความที่สามารถกดเพื่อเปิดเนื้อหาฉบับเต็มได้ทันที
- **การนำทาง (Navigation):** เมนูและลิงก์ต่างๆ เชื่อมโยงกันครบถ้วน ไม่มีลิงก์เสีย 
- **Animation & Interaction:** มีลูกเล่นแอนิเมชันเมื่อเลื่อนหน้า (Scroll Animation) และปุ่มกดต่างๆ ตอบสนองเมื่อเอาเมาส์ชี้ (Hover Effect)

## 🎨 การออกแบบ (Design Implementation)
- **Layout:** นำโครงสร้างหลักมาจาก Figma โดยใช้ Bootstrap Grid System (`container`, `row`, `col`) เข้ามาช่วยจัดวางให้เป็นระเบียบ
- **Color:** ใช้โทนสีสว่าง ขาว-เทาอ่อน สลับกับน้ำเงิน/ฟ้า เพื่อให้ความรู้สึกสะอาดและเชื่อมโยงกับ "น้ำ" ตามธีมสารานุกรมสัตว์น้ำ
- **Typography:** ใช้ฟอนต์ **Kanit** จาก Google Fonts ซึ่งอ่านง่าย เป็นทางการแต่ดูทันสมัย
- **Components:** นำดีไซน์จาก Figma มาประกอบเป็นโค้ด เช่น Navbar แบบโปร่งแสง (Glassmorphism), Card แบบมีเงา, ปุ่มแบบขอบมน (Rounded Pill)

## 📱 การรองรับหน้าจอ (Responsive Design)
- ใช้งาน Bootstrap Grid System (`col-sm`, `col-md`, `col-lg`) ในการจัดการ Breakpoints
- เมนูบาร์จะถูกย่อเป็นปุ่มแฮมเบอร์เกอร์ (Hamburger Menu) เมื่อดูผ่านมือถือ
- การ์ดและรูปภาพจะปรับขนาดเองอัตโนมัติ ไม่ล้นหน้าจอ (1 คอลัมน์บนมือถือ, 2-3 คอลัมน์บนไอแพด, และ 4-5 คอลัมน์บนเดสก์ท็อป)

## 🤖 การใช้ AI (AI Usage Report)
- **ใช้ AI ตัวใด:** Google Gemini (ผ่านระบบ Antigravity)
- **ใช้ในขั้นตอนใด:** ช่วยตรวจสอบข้อกำหนดโปรเจกต์ (Debugging), ช่วยแก้ปัญหาเรื่องลิงก์เสีย (Routing/Navigation), และช่วยเติมเนื้อหารายละเอียดลงใน Modal (Content Generation)
- **Prompt สำคัญ:**
  1. *"ฉันมีลิงก์งานออกแบบจาก Figma (แนบลิงก์) โปรดช่วยวิเคราะห์โครงสร้างเว็บไซต์นี้ แล้วเขียนโค้ด HTML5 โดยใช้ Bootstrap 5 Grid System (container, row, col) ในการแบ่งสัดส่วนหน้าเว็บให้ตรงกับดีไซน์ แบ่งเป็น Section ย่อยๆ ให้ชัดเจน (เช่น Navbar, Hero Banner, Content, Footer) ยังไม่ต้องใส่ CSS แบบละเอียด ขอแค่โครงสร้างที่ถูกต้องก่อน"*
  2. *"จากโครงสร้าง HTML ที่ได้ ให้ช่วยเขียนไฟล์ style.css แยกต่างหาก โดยดึงค่าสี (Color Palette) และฟอนต์ (Typography) ให้ตรงกับใน Figma มากที่สุด และที่สำคัญคือต้องทำให้เว็บเป็น Responsive รองรับการแสดงผลบนมือถือ (Mobile-friendly) หากมีส่วนไหนที่บนหน้าจอคอมเป็นแนวนอน ให้ปรับเป็นแนวตั้ง (Stack) เมื่อดูผ่านมือถือ"*
  3. *"ในหน้า 'สัตว์น้ำจิ๋ว' (animals.html) ฉันไม่อยากให้ปุ่ม 'อ่านรายละเอียด' เด้งไปหน้าใหม่ ช่วยแก้ไขโค้ดปุ่มและการ์ด ให้ทำงานร่วมกับ Bootstrap Modal (หน้าต่าง Pop-up) แทน เมื่อกดปุ่มแล้วให้มีหน้าต่างเด้งขึ้นมาพร้อมแสดงข้อมูลของสัตว์ตัวนั้นๆ โดยที่หน้าเว็บยังคงสไตล์เดิมจาก Figma ไว้"*
- **ผลลัพธ์ที่นำมาใช้โดยตรง:** เนื้อหาความรู้และรายละเอียดของสัตว์น้ำ/บทความ ที่ AI ช่วยเขียนเพิ่มเติมให้สมบูรณ์ นำมาใส่ใน Modal
- **ผลลัพธ์ที่ต้องแก้ไข และแก้ไขอย่างไร:** เดิมที AI ช่วยแปลงไฟล์เป็นนามสกุล `.php` แต่เพื่อให้โปรเจกต์นี้สามารถนำขึ้น GitHub Pages (Static Hosting) ได้ จึงต้องสั่งให้ AI เขียนสคริปต์เพื่อเปลี่ยนโค้ดและลิงก์ทั้งหมดกลับมาเป็น `.html` ล้วน
- **ตรวจสอบความถูกต้องอย่างไร:** นำโค้ดทั้งหมดมารันและทดสอบการกดปุ่ม "อ่านรายละเอียด" ทุกปุ่มในเครื่องตัวเอง (Local) และใช้ฟีเจอร์ Responsive Mode ใน Chrome DevTools เพื่อจำลองการย่อหน้าจอเพื่อทดสอบระบบมือถือ
- **ตัวอย่างคำตอบที่ AI ให้ผิดและแก้ปัญหาอย่างไร:** ตัวอย่างเช่น ตอนสั่งให้ AI แปลงโค้ด AI ทำการบันทึกไฟล์ผิดฟอร์แมต ทำให้ภาษาไทยกลายเป็นตัวยึกยือ (Mojibake/Encoding Error) ผู้จัดทำแก้ปัญหาโดยสั่งให้ AI เขียนสคริปต์แก้ Encoding ให้กลับมาเป็น UTF-8 เพื่อให้แสดงภาษาไทยได้ถูกต้อง
- **สิ่งที่ได้เรียนรู้จากการใช้ AI:** การใช้ AI ช่วยลดเวลาการพิมพ์ข้อมูลได้มาก และช่วยตรวจจับจุดบกพร่อง (ลิงก์ตาย) ที่เรามองข้ามไปได้ แต่เราในฐานะผู้พัฒนาต้องเข้าใจโครงสร้างเว็บพื้นฐานก่อน เพื่อที่จะสามารถตรวจสอบความถูกต้องและสั่งให้ AI ทำงานแก้ไขปัญหาได้อย่างตรงจุด

## 🚀 ขั้นตอนการเผยแพร่ (Deployment)
- **Hosting:** GitHub Pages
- **Build command:** ไม่มี (เนื่องจากเป็น Static HTML)
- **ขั้นตอน Deploy:** 
  1. สร้าง Repository บน GitHub ในบัญชีของตนเอง และทำการ Push โค้ดทั้งหมดขึ้นไปที่ Branch `main`
  2. เข้าไปที่เมนู **Settings** ของ Repository บนเว็บ GitHub
  3. เลือกแถบเมนูด้านซ้ายที่ชื่อว่า **Pages**
  4. ตรงส่วน Build and deployment หัวข้อ Source ให้เลือก `Deploy from a branch`
  5. ตรงหัวข้อ Branch เลือกเป็น `main` แล้วกดปุ่ม **Save**
  6. รอระบบประมวลผลประมาณ 1-2 นาที เว็บไซต์จะออนไลน์ทันทีที่ลิงก์ที่ GitHub ให้มา

## 🚧 ปัญหาที่พบและการเรียนรู้ (Challenges)
- **ปัญหาที่พบ:** การจัดการลิงก์ในหน้าเว็บแบบ Static HTML มักจะมีปัญหาเมื่อต้องสร้างหน้าย่อยเยอะๆ (เช่น หน้ารายละเอียดสัตว์แต่ละตัว) ทำให้จัดการยากและไฟล์รก
- **แนวทางแก้:** เปลี่ยนมาใช้เทคนิค Bootstrap Modal (หน้าต่าง Pop-up) แทนการสร้างไฟล์ HTML ย่อยใหม่ทุกตัว ทำให้เว็บไซต์ใช้งานง่ายขึ้นและโค้ดเป็นระเบียบ
- **สิ่งที่เรียนรู้:** การประยุกต์ใช้ Component จาก Bootstrap และความสำคัญของการทำ Responsive Design ที่ต้องคิดเผื่อผู้ใช้งานมือถือเป็นหลัก
